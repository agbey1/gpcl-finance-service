# Ghana Publishing Company Limited (GPCL) — Finance & Accounting Service

Standalone enterprise microservice and management platform for GPCL commercial finance, double-entry general ledger, accounts receivable, statutory Ghana tax compliance, bank reconciliation, and financial analytics.

## 📖 Comprehensive User Manual
- **[Download / View User Manual (PDF)](file:///c:/projects/gpcl-finance-service/GPCL_Finance_User_Manual.pdf)**
- **[Read Online Manual (Markdown)](file:///c:/projects/gpcl-finance-service/USER_MANUAL.md)**

## 🚀 Getting Started

First, run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) or [http://localhost:3006](http://localhost:3006) with your browser.
